# 🛒 OLX Store

Projeto web inspirado na plataforma OLX, desenvolvido com foco em estudo de **React**, manipulação de estado e construção de interfaces modernas para anúncios online.

---

## 📌 Sobre o projeto

O **OLX Store** é uma aplicação que simula um marketplace de compra e venda de produtos, permitindo visualizar anúncios, editar informações e trabalhar com rotas dinâmicas.

Este projeto foi criado com fins educacionais para praticar conceitos de desenvolvimento front-end, especialmente com React, durante minhas aulas na Digital college.

---

## 🚀 Funcionalidades

- 📄 Listagem de anúncios  
- 🔍 Visualização de detalhes de cada produto  
- ✏️ Edição de anúncios `Edição temporaria dos dados`
- 🔗 Rotas dinâmicas com `useParams`  
- ⚛️ Gerenciamento de estado com `useState`  
- 🎨 Interface estilizada com Tailwind CSS `Pegando estilo das paginas com o FloatUI`

---

## 🛠️ Tecnologias utilizadas

- React.js  
- React Router DOM  
- JavaScript (ES6+)  
- Tailwind CSS

## ⚙️ Como executar o projeto

### Pré-requisitos

- Node.js instalado
- npm ou yarn

### Passo a passo

```bash
# Clone o repositório
git clone https://github.com/yurysmaciel/Olx-Store.git .

# Instale as dependências
npm install

# Rode o projeto
npm run dev

```
